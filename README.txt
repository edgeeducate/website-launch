IMPORTANT: THE ADMIN CONTENT EDITOR WON'T WORK HERE
===============================================
GitHub Pages only serves static files - it cannot run PHP.
This means the admin.php content editor we built (login, edit text,
save changes) ONLY works on a host that supports PHP, like Hostinger.

For now, on GitHub, any content change means asking Claude to edit
the code directly - the same as before we built the admin panel.

Once you migrate to your paid hosting (Hostinger, once your payment
gateway/setup is ready), switch to the OTHER package - the one with
admin.php, cms-config.php, and content.json included - and the
self-service editor will work there.
